Design system

Calm, on purpose.

The tokens and components behind the dashboard. This page uses the real stylesheet, so what you see here is what ships.

Principles

Four rules decide most design questions in this product.

  • Calm over urgent

    A job search is stressful already. No red alarms, no streaks, no countdowns. Caution is amber and always says why.

  • Honest numbers

    Small samples are labelled small. A number never appears without its label and, when it matters, its range.

  • Text carries meaning

    Colour, shape and position only add emphasis. Every state has words, so it survives forced colors and colour blindness.

  • Works with a keyboard

    Every control is a real button, link or field with a visible focus ring and a 40 px target.

Motion

Motion is short and only confirms an action. Two durations: 120 ms for controls, 250 ms for bars that change width. Everything is switched off when the system asks for reduced motion.

Components

Each component shows the real markup, when to use it, and what it does for accessibility.

Button

The one thing to do on this page is a filled button. Everything else is ghost. Use small for dense rows, caution only for actions that lose data.

Markup
<button class="btn" type="button">Add listing</button>
<button class="btn ghost" type="button">Download CSV</button>
<button class="btn ghost sm" type="button">Edit</button>
<button class="btn caution" type="button">Clear data</button>
<button class="btn" type="button" aria-disabled="true">Save</button>
<button class="btn ghost" type="button" aria-pressed="true">Done</button>

Accessibility. Real <button> elements. Minimum height 40 px (WCAG 2.2 target size asks for 24). Disabled uses aria-disabled so it stays focusable and explainable. Toggles use aria-pressed and change their text, not only their colour.

Tag

A status the reader needs at a glance. Always has text. Colour only adds emphasis.

<span class="tag accent">Interview</span>
<span class="tag closed">Closed</span>
<span class="tag calm">Steady</span>
<span class="tag caution">Check this</span>

Accessibility. Text carries the meaning, so the tag still works in forced-colors mode and for colour-blind readers. Contrast is checked in both themes on the table above.

Chip filter and segmented control

Chips filter a list. A segmented control switches between two or three modes of the same view.

Markup
<div class="chips" role="group" aria-label="Filter">
  <button class="chip" type="button" aria-pressed="true">All</button>
  <button class="chip" type="button" aria-pressed="false">Waiting</button>
  <button class="chip" type="button" aria-pressed="false">Interview</button>
</div>
<div class="seg" role="group" aria-label="Language" style="max-width:160px;margin-top:12px">
  <button type="button" aria-pressed="true">EN</button>
  <button type="button" aria-pressed="false">ES</button>
</div>

Accessibility. A group with an aria-label, each button with aria-pressed. Arrow keys are not needed because every option is a tab stop. The pressed state has a fill and a heavier weight.

Field

A label above, a hint below, an error as text. The error never relies on colour alone.

Used only in the follow-up drafts you copy.
Add https:// at the start.
Markup
<div class="field">
  <label class="label" for="ds-name">Your name</label>
  <input class="input" id="ds-name" type="text" aria-describedby="ds-name-h">
  <span class="hint" id="ds-name-h">Used only in the follow-up drafts you copy.</span>
</div>
<div class="field" style="margin-top:16px">
  <label class="label" for="ds-link">Portfolio link</label>
  <input class="input" id="ds-link" type="url" value="joselblas" aria-invalid="true" aria-describedby="ds-link-e">

Accessibility. The label is a real label element. The hint and the error are linked with aria-describedby. Invalid fields get a thicker border plus the message.

Accessibility. The icon is decorative and hidden from assistive tech, the first word does the work. Use role="status" only for a note that appears after an action.
