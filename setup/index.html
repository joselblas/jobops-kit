Setup

Some assembly.
Not much.

Twelve steps, one action each. Every step tells you what you should see before you go on. About 30 minutes. No code.

Start at step 1Read it as text

Before you start

Check the parts.

  • 1×A Claude account with ProjectsThe assistant lives in a Project.
  • 1×Chrome or EdgeSaves straight to your file. Other browsers can download instead.
  • 1×Your current CVThe source for your fact file.
  • 1×A private folderOn your computer, outside any Git repo.
  • 30MinutesMostly writing down facts about yourself.

You do not need Python or Git to start.

Instructions

Follow in order.

Two halves. Parts 1 to 4 build the Claude assistant. Part 5 opens the dashboard. You can stop after either.

Part 1

Get the files

1

Download the kit

Open github.com/joselblas/jobops-kit. Click Code, then Download ZIP.

You should see

A file called jobops-kit.zip in your downloads.

2

Unzip it

Double-click the ZIP.

You should see

A folder with AGENTS.md in it, and folders named playbooks, templates and app.

Part 2

Make your private folder

3

Create a folder, away from the kit

Name it jobops-private. Put it somewhere else, for example in Documents. Your real data never goes in the kit folder.

You should see

An empty folder, separate from the kit.

4

Copy three templates into it

From templates/ copy career-context.example.md, profile.example.yml and tracker.example.csv. Remove .example from each name.

You should see

career-context.md, profile.yml and tracker.csv in jobops-private.

Part 3

Write your facts

5

Fill in career-context.md

Copy facts from your CV: name, languages, education with exact dates, each job with results you can defend. List what you must never claim. If you do not know a fact, leave it blank. A blank is safe. A guess is not.

You should see

No template words left, such as Name: with nothing after it. This file is the only source for every CV Claude writes.

6

Set your gates in profile.yml

Your target roles, remote mode, where you are based, and which regions count as eligible. Add companies you will never work for.

You should see

No placeholders left, such as Country, Region or ExampleCorp.

Part 4

Create the Claude Project

7

Create a Project

In Claude, make a new Project. Call it Job search.

You should see

An empty Project with a place to add files.

8

Upload your files

Add AGENTS.md, everything in playbooks/, and your three private files.

You should see

Every file listed in the Project.

9

Add one line of instructions

Paste: Read AGENTS.md first, every session.

You should see

The line saved in the Project instructions.

10

Ask for the first scout

Start a chat and type: Scout today's listings and run the gates.

You should see

A short note: new leads with scores, gates checked with quoted evidence, and what was ruled out and why. Nothing is applied or sent.

Part 5

Open the dashboard

11

Look around first

Open the demo. It uses fictional data.

You should see

An overview with a funnel, odds and a fit radar.

12

Open your own tracker

Open app/index.html in Chrome or Edge. Click Open and edit and choose jobops-private/tracker.csv.

You should see

Your listings. Edits save to the file. Nothing leaves your computer.

After setup

A weekly rhythm.

Each search day

Ask the Project to scout. Pick leads. Review each tailored CV before anything is filled.

After you apply

Dashboard, Log an update.

When replies arrive

Log an update, or accept Proposed updates from an email sweep.

After 3 quiet weeks

Follow-ups. Copy a draft and send it yourself.

Once a week

Weekly review. Five minutes.

If something looks wrong

Quick fixes.

The dashboard shows sample dataYou have not opened your file. Click Open and edit.
There is no Open buttonUse Chrome or Edge, or Load tracker.csv and Download CSV to save.
Claude invents a factAdd the real fact to career-context.md, upload it again, and say what it got wrong.
Scout ignores your gatesCheck profile.yml was uploaded and has no placeholders.
A listing said remote but is notExpected. Gates are checked on the employer's page. Tell Claude. It logs the reason.
Keep it private

Never commit career-context.md, profile.yml, tracker.csv, cv/ or logs/.

They are gitignored. Run python3 scripts/privacy_check.py before you publish a fork.
