Setup

Some assembly.
Not much.

Nine steps, one action each. Every step tells you what you should see before you go on. About 15 minutes. No code.

Start at step 1Read it as text

Before you start

Check the parts.

  • 1×A Claude account with ProjectsThe assistant lives in a Project.
  • 1×Chrome or EdgeSaves straight to your file. Other browsers can download instead.
  • 1×Your current CVClaude starts from it and asks you to confirm each fact.
  • 1×A private folderOn your computer, outside any Git repo.
  • 15MinutesMostly answering questions about yourself.

You do not need Python or Git to start. Everything is context, written as text. The dashboard and your folder stay on your computer. What you give Claude is processed under your account's privacy settings. Read the short privacy note.

Instructions

Follow in order.

Nine steps. Parts 1 to 4 build the Claude assistant and run your first search. The dashboard is step 9. You can stop after step 8.

Part 1

Get the kit

1

Download and unzip the kit

Open github.com/joselblas/jobops-kit. Click Code, then Download ZIP, then double-click the ZIP.

You should see

A folder with README.md in it, and folders named skills, app and playbooks.

2

Create a private folder, away from the kit

Name it jobops-private. Put it somewhere else, for example in Documents. Your real data lives here and nowhere else.

You should see

An empty folder, separate from the kit.

Part 2

Set up Claude

3

Add the five skills

In Claude, open Settings, then Skills. Add jobops-start, jobops-screen, jobops-craft, jobops-apply and jobops-review from the skills/ folder. If Claude asks for a zip, zip each folder.

You should see

Five JobOps skills listed and switched on.

4

Make a Project

Create a Project called Job search. In its instructions paste: Use the JobOps skills for job search tasks.

You should see

An empty Project with the line saved in its instructions.

Part 3

Say start

5

Type Start

Open a chat in the Project. Attach your CV if you have one. Type Start. Claude explains how it works, asks what to keep private, then asks questions one at a time and shows you each fact before keeping it. If you do not know a fact, leave it blank. A blank is safe. A guess is not.

You should see

Three files at the end: career-context.md, profile.yml and tracker.csv.

6

Save the three files in jobops-private

Everything Claude knows about you is text, and now it is in files you own.

You should see

career-context.md, profile.yml and tracker.csv in jobops-private.

7

Upload the same three files to the Project

Claude cannot see your folder, so this is how it keeps your facts for the next chat.

You should see

The three files listed in the Project.

Part 4

Search and look

8

Ask for the first scout

Start a new chat in the Project and type: Scout today's listings and run the gates.

You should see

A short note: new leads with scores, gates checked with quoted evidence, and what was ruled out and why. Nothing is applied or sent.

9

Open your own dashboard

Open app/index.html in Chrome or Edge. Click Connect folder and choose jobops-private. Want to look first? Try the demo with fictional data.

You should see

Your listings. Edits save to the file. Nothing leaves your computer.

After setup

A weekly rhythm.

Each search day

Ask the Project to scout. Pick leads. Review each tailored CV before anything is filled.

After you apply

Dashboard, Log an update.

When replies arrive

Log an update, or accept Proposed updates from an email sweep.

After 3 quiet weeks

Follow-ups. Copy a draft and send it yourself.

Once a week

Weekly review. Five minutes.

If something looks wrong

Quick fixes.

Claude does not offer to startCheck jobops-start is switched on in Settings, Skills, or type: Use the jobops-start skill.
The dashboard shows sample dataYou have not connected your folder. Click Connect folder.
Connect folder does nothingUse Chrome or Edge, or Load tracker.csv and Download CSV to save.
Claude invents a factAdd the real fact to career-context.md, upload it again, and say what it got wrong.
Scout ignores your gatesCheck profile.yml was uploaded and has no placeholders.
A listing said remote but is notExpected. Gates are checked on the employer's page. Tell Claude. It logs the reason.
Keep it private

Never commit career-context.md, profile.yml, tracker.csv, cv/ or logs/.

They are gitignored. Run python3 scripts/privacy_check.py before you publish a fork.
